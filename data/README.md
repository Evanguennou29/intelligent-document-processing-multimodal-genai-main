# Dossier de donnees

| Dossier      | Contenu                                                        |
| ------------ | -------------------------------------------------------------- |
| `raw/`       | Documents importes (images, PDF), ranges par type de document. |
| `processed/` | Resultats JSON produits par le pipeline.                       |

Ces deux dossiers sont **ignores par git** (voir `.gitignore`) : ils ne
contiennent que des donnees locales, jamais de documents personnels.
